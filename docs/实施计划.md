# 家庭管理系统 · 实施计划 v2（已定稿）

> 制定时间：2026-10-21 · 状态：**决策已拍板，进入实施**
> 目标：把「家味 · 家庭点餐系统」演进为「家庭管理系统」（饮食 + 账务 + 健康 + 智能家电 + 家务）

---

## 已拍板的决策

| # | 决策点 | 结论 |
|---|--------|------|
| A | 学习模块数据 | **JSON blob**（`member_data` 表，跑顺再拆专表） |
| B | 鉴权 | **每人密码**（argon2 哈希 + JWT；密码可后置设置，NULL=免密登录） |
| C | 智能家电 | **设备台账先行**，HA 桥接后置（有硬件再排期） |
| D | 提醒通知 | **纯站内**（不做 push / 微信） |
| E | 阶段 0 地基 | **取消**：不做 git、不做 uploads 备份、不做三模块导出/导入（数据服务端化后进 MySQL 备份体系） |

---

**数据底座 + 密码体系 → 家庭档案与提醒 → 仪表盘/PWA → 设备台账 → 模块深化**
